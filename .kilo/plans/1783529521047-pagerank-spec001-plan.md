# Plan de Implementación — PageRank (SPEC-001 v2.0 + ARCH_DESIGN)

Proyecto: `Taller4_PageRank`. Implementación C++17 + Eigen del algoritmo PageRank
(método de las potencias sobre la Matriz de Google `G`), procesando 5 casos y
exportando CSV. Sigue estrictamente el contrato de `SDD/ARCH_DESINGN.md §7/§8`
y `SDD/SPECS/SPEC-001.md`.

Estructura de carpetas ya creada: `src/`, `python/`, `resultados/tablas/`,
`resultados/graficos/`, `build/`.

---

## Contratos (fuente de verdad)

- **Entrada:** matriz de transición `M` ya normalizada (columnas suman 1; sumideros
  suman 0). Se hardcodea en `casos_prueba`. NO se construye M desde adyacencia.
- **`G = d·M + (1-d)/n · J`**, `d = 0.85`, `J` = matriz de unos.
- **Método de potencias:** `v₀ = [1/n…1/n]`, `vₖ₊₁ = G·vₖ`,
  parar si `||vₖ₊₁ - vₖ||₂ < ε = 1e-8`, `k_max = 1000`. Normalizar al final.
- **CSV de salida** (ver ARCH_DESIGN §8):
  - `resultados/casoN_pagerank.csv`: `pagina,pagerank,grado_entrada,grado_salida`
  - `resultados/casoN_convergencia.csv`: `iteracion,error_norma,pagerank_0,…,pagerank_{n-1}`
  - `resultados/casoN_matriz_M.csv` / `casoN_matriz_G.csv`: `fila,columna,valor` (largo, base 0)
  - `resultados/resumen_comparativo.csv`: `caso,descripcion,n_paginas,iteraciones,error_final,convergencia,tiempo_segundos,pagerank_max,pagerank_min,suma_pagerank`

## Tarea 1 — `CMakeLists.txt` (raíz)

Crear `CMakeLists.txt` según SPEC-001 §6.1:
- `cmake_minimum_required(VERSION 3.16)`, `project(PageRank LANGUAGES CXX)`.
- `set(CMAKE_CXX_STANDARD 17)`, `CMAKE_CXX_STANDARD_REQUIRED ON`.
- Soporte toolchain vcpkg opcional (`VCPKG_ROOT`).
- `find_package(Eigen3 REQUIRED)`.
- `add_executable(pagerank src/main.cpp src/pagerank_core.cpp src/casos_prueba.cpp src/exportador.cpp)`.
- `target_link_libraries(pagerank PRIVATE Eigen3::Eigen)`.
- `target_include_directories(pagerank PRIVATE src)`.
- Flags: `/Wall` (MSVC), `-Wall -Wextra -O2` (GNU/Clang).

## Tarea 2 — `src/pagerank_core.hpp`

Implementar la cabecera del contrato ARCH_DESIGN §7.1 / SPEC-001 §2.1:
- `struct ResultadoPageRank { Eigen::VectorXd pagerank; int iteraciones; double error_final; bool convergio; double tiempo_ejecucion; std::vector<double> historial_error; std::vector<Eigen::VectorXd> historial_pagerank; }`
- `class PageRank` con:
  - `PageRank(const Eigen::MatrixXd& transicion, double d = 0.85)`
  - `Eigen::MatrixXd construir_matriz_google() const;`
  - `ResultadoPageRank ejecutar(double tolerancia = 1e-8, int max_iter = 1000);`
  - getters: `get_n_paginas()`, `get_factor_amortiguamiento()`, `get_matriz_google()`, `get_matriz_transicion()`
  - validaciones: `validar_matriz_transicion() const`, `calcular_suma_columnas() const`
  - privados: `transicion_`, `google_`, `d_`, `n_`
- Incluir `<Eigen/Dense>`, `<vector>`, `<string>`, `<chrono>`.

## Tarea 3 — `src/pagerank_core.cpp`

- `construir_matriz_google()`: `google_ = d_ * transicion_ + (1.0 - d_) / n_ * J` (SPEC-001 §4.1 / ARCH §7.2).
- `ejecutar()`: SPEC-001 §4.2 / ARCH §7.4. Guardar historiales (push inicial de error 0 y vector v₀). Calcular `error = (v - v_anterior).norm()`. Normalizar `v = v / v.sum()` al final. Registrar `tiempo_ejecucion` con `high_resolution_clock`.
- `validar_matriz_transicion()` / `calcular_suma_columnas()`: ARCH §7.3 (columna suma 1 válida, 0 = sumidero).
- Getters devuelven los miembros correspondientes.

## Tarea 4 — `src/casos_prueba.hpp`

Contrato SPEC-001 §2.2:
- `struct CasoPrueba { int id; std::string nombre; std::string descripcion; Eigen::MatrixXd transicion; }`

## Tarea 5 — `src/casos_prueba.cpp`

Hardcodear las 5 matrices M del profesor exactamente como SPEC-001 §2.2
(caso_1 a caso_5 con sus valores). `obtener_todos()` y `obtener_caso()` con
descripciones: "3x3 con sumidero", "4x4 regular", "8x8 complejo",
"5x5 con estructura", "3x3 con sumidero". `default` lanza `std::invalid_argument`.

## Tarea 6 — `src/exportador.hpp`

Contrato SPEC-001 §2.3:
- `static bool exportar_pagerank(archivo, ResultadoPageRank, int n_paginas)`
- `static bool exportar_convergencia(archivo, ResultadoPageRank)`
- `static bool exportar_matriz_google(archivo, Eigen::MatrixXd G)`
- `static bool exportar_matriz_transicion(archivo, Eigen::MatrixXd M)`
- `static bool exportar_resumen(archivo, vector<ResultadoPageRank>, vector<string> nombres_casos)`

## Tarea 7 — `src/exportador.cpp`

- `exportar_pagerank`: CSV con cabecera `pagina,pagerank,grado_entrada,grado_salida`.
  Calcular `grado_entrada` = suma fila de M (entradas hacia el nodo), `grado_salida`
  = suma columna de M (debe ser 1 o 0 sumidero). Iterar nodos.
- `exportar_convergencia`: una fila por iteración del `historial_*`; columnas
  `iteracion,error_norma,pagerank_0…pagerank_{n-1}`.
- `exportar_matriz_google` / `exportar_matriz_transicion`: formato largo
  `fila,columna,valor` (todos los n×n elementos, base 0).
- `exportar_resumen`: cabecera de 10 columnas incl. `suma_pagerank`,
  `pagerank_max/min` de `resultado.pagerank`.
- Retornar `bool` (éxito de `std::ofstream`).

## Tarea 8 — `src/main.cpp`

Orquestador SPEC-001 §2.4:
- `d=0.85`, `tolerancia=1e-8`, `max_iter=1000`. Imprimir parámetros.
- Por cada caso de `CasosPrueba::obtener_todos()`: validar M (warning si no),
  construir G, `ejecutar()`, imprimir resultados, exportar 4 CSV con prefijo
  `../resultados/casoN_`.
- Al final: `exportar_resumen("../resultados/resumen_comparativo.csv", …)`.

## Validación

1. **Compilar** (Windows MSVC): `mkdir build && cd build && cmake .. -G "Visual Studio 17 2022" && cmake --build . --config Release` (SPEC-001 §6.2).
2. **Ejecutar** `.\Release\pagerank.exe`; verificar consola tipo ARCH §9.4.
3. **Criterios numéricos** (ARCH §10.1 / SPEC-001 §5.1):
   - `pagerank.sum() == 1.0 ± 1e-6`; `minCoeff() >= 0`.
   - `error_final < 1e-8`; `iteraciones < 1000` para los 5 casos.
   - `G.colwise().sum()` = vector de unos.
4. **CSV generados** en `resultados/`: 5×4 archivos + `resumen_comparativo.csv`, con columnas exactas del contrato §8.
5. **Verificaciones por caso** (SPEC-001 §5.2): caso 1 y 5 → nodo sumidero (2) con mayor PageRank; caso 2 → casi uniforme; etc.

## Riesgos / notas

- `grado_entrada`/`grado_salida` en pagerank CSV se derivan de `M` (transición); no del grafo original (no disponible). Consistente con SPEC-002 que los consume.
- Índices de matrices en CSV base 0 (requerido por SPEC-002 §2.1).
- No crear `casos_prueba/*.txt` ni módulo `graph_loader` (eliminados en v2.0).
- Python/SPEC-002 queda fuera de este plan (solo C++/SPEC-001).
